# Frontend prototype

`index.html` is the single-file prototype (dummy data, no backend). Open it in a browser or run `npx serve frontend`.

- Edit the `PHOTOS` object at the top of the script to add images (empty = gradient fallback).
- Backend swap points: `/api/auth/login`, `/api/slots`, `/api/appointments`, `/api/queue/today`, `/api/dashboard/summary`, `/api/health`.
